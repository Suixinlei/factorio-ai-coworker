Version: 0.8.1
Date: 2026-10-08

  Changes:
    - Unified ACTION model: every step key is "action"; compound actions
      (formerly "skills") and atomic actions (formerly "primitives")
      dispatch through the same key (legacy "skill" key stays an alias).
      Batch-first parameters everywhere a list makes sense.
    - place_batch is now a PRECISE GHOST EXECUTOR: it builds ONLY listed
      entities that already exist as ghosts (plan_blueprint first), matching
      exact position and direction, with an atomic inventory pre-check and
      post-build audit. Nothing un-ghosted is ever placed, so mixed-agent
      ghost fields stay untouched.
    - New generic resupply action fill(items? | item+count, radius?):
      explicit items go to every nearby entity that accepts them (fuel slot
      for accepted fuels, container/machine input otherwise); without items
      each device gets what it needs (burners: best accepted fuel by
      category+value; machines: recipe ingredients; labs: science packs;
      turrets: ammo). Replaces fuel_all (coal-only).
    - New generic fetch action collect(items | item+count, radius?):
      takes EXACT quantities from nearby containers, nearest first; there
      is deliberately NO take-everything mode. Replaces loot_chests.
    - Removed compound actions build_miner and build_smelter — superseded
      by the ghost-first flow (plan_blueprint → place_batch /
      plan_mining_outpost for mining arrays).

Version: 0.8.0
Date: 2026-10-08

  Features:
    - New skill plan_mining_outpost: ONE call turns an ore patch into a
      complete ghost layout of mining drills + output belts + power poles.
      Canonical outpost rules (official wiki) with ALL geometry derived from
      live prototypes: drills on a lattice of step 2H+1 (H =
      floor(mining_drill_radius)) cover the patch fully with no
      overlap (electric 3x3/5x5 -> step 5; big-mining-drill 5x5/13x13 ->
      step 13); paired drill rows face each other onto shared belt rows
      (drop offset floor(F/2)+1); power poles chained on street rows
      between pairs, spacing min(wire-1, 2*supply+1) from the prototype
      (2.0 poles rebalanced - medium is 7x7 supply / 9 wire). Drill, pole
      and belt tiers are parameters (drill/pole/belt); a pole too small for
      the lattice is rejected in preflight with the substation hint.
      Params: resource, x/y (patch centre), direction (belt flow, default
      east), drill, pole, belt, min_ore (default 4), max_drills (default
      120), radius (default 64). Reports ore coverage % and the exact item
      list for gather/craft + build_ghosts; re-runs extend the plan.
      Ghost semantics follow the 0.7.10 calibration (water-guarded direct
      create, no false-strict can_place gate).
