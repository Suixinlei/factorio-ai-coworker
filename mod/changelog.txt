Version: 0.2.0
Date: 2026-10-08

  Breaking action API release:
    - Aligns atomic and batch action names (for example insert/batch_insert,
      mine/batch_mine, and build_ghost/batch_build_ghost).
    - Removes legacy skill, primitive, and duplicate action entry points.
    - Adds file-backed batch plans with automatic chunking for large entity
      lists and cleanup regions.
